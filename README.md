### [Brainmerge](https://github.com/ruben4reall/brainmerge): every Claude account you own, side by side, with one memory

A native macOS app for people with more than one Claude account. Each account gets its own window, name, color and Dock icon, and all of them share one memory of your projects, or keep one each. It only launches the official Claude app and Claude Code, never touches a password or a token, and makes no network call.
